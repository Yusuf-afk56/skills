# Dr Schaida Schirwani — Website

Next.js 16 + TypeScript + Tailwind CSS + Framer Motion website for Dr Schaida Schirwani, Consultant Clinical Geneticist.

## Stack

- **Next.js 16** (App Router)
- **TypeScript**
- **Tailwind CSS v4**
- **Framer Motion** — scroll-triggered entrance animations, AnimatePresence mobile menu
- **lucide-react** — SVG icons
- **shadcn-compatible** project structure (`components/ui/`, `lib/utils.ts`)

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Sections

- **Hero** — gradient headline, credential pills, Unsplash hero image
- **About** — biography and qualifications
- **Expertise** — 6 clinical speciality cards
- **Private Practice** — 4 service cards on navy gradient
- **Research & Publications** — stats and selected papers
- **Contact** — appointment request form with success state
